# Contributing

Thank you for helping improve the public Alle's ClinX technical repository.

This is a **controlled corporate documentation repository**. Public contributions are welcome where they improve accuracy, accessibility or machine readability, but controlled technical documents remain subject to internal review before publication.

## Good contributions

Useful contributions include:

- reporting broken links or missing documents;
- identifying metadata mismatches;
- correcting typographical or formatting errors;
- improving accessibility of public repository content;
- proposing fixes to public scripts or structured-data files;
- reporting inconsistencies between document indexes and published files.

## Controlled technical content

SDS, TDS, SOP and product-use material can have safety and compliance implications. Do not submit speculative changes to:

- product chemistry;
- concentration or active-ingredient data;
- dilution instructions;
- compatibility statements;
- PPE requirements;
- storage or hazard information.

If you believe controlled technical information is incorrect, report the exact document, section and supporting evidence to **care@allesclinx.com**.

## Pull requests

Where a pull request is appropriate:

1. keep the change narrowly scoped;
2. explain what was changed and why;
3. reference the affected file or source;
4. avoid unrelated formatting changes;
5. do not include secrets, customer data or confidential commercial information.

Submission does not imply acceptance or publication. Alle's ClinX retains editorial and technical control over official documentation.
