# Document Use and Authenticity

This repository is the public, version-controlled technical mirror for Alle's ClinX documentation.

## Authentic copies

A document should be treated as the repository's current published copy only when:

1. it is present on the `main` branch in the appropriate controlled collection;
2. its path is present in `data/document-index.json`; and
3. its SHA-256 digest matches `checksums.sha256`.

Git history and controlled GitHub Releases preserve prior publication states where a historical reference is required.

## Modified copies

Do not alter an Alle's ClinX controlled PDF and present the modified file as an official Alle's ClinX document. Internal annotations, translations, excerpts or local working copies should be clearly identified as modified or uncontrolled copies.

## Safety and technical authority

Repository metadata, indexes and convenience datasets support discovery and integration. They do not replace the current product label or the controlled safety and technical documents themselves.

For safety-critical decisions, use the current product label and the latest applicable SDS/TDS and approved operating procedure.
