# Repository Integrity & Release Controls

This directory contains generated and explanatory material for the public document library.

- [Current library status](./status.md) — generated by automated QA.
- [SHA-256 checksums](../checksums.sha256) — integrity verification for every public PDF.
- [Release manifest](../data/release-manifest.json) — machine-readable document integrity metadata.
- [Document register](../data/document-register.csv) — current controlled-document register.
- [Legacy filename map](../data/legacy-filename-map.csv) — migration reference from retired product-document filenames.
- [Document use and authenticity](../DOCUMENT-USAGE.md) — authenticity and modified-copy guidance.

The canonical PDFs remain in `tds/`, `usage-guides/`, `sops/`, `sds/` and `resources/`.
