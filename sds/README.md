## Integrity and version control

`manifest.csv` records the source filename, file size, and SHA-256 checksum for each document in the supplied release bundle. This allows future revisions to be tracked without silently replacing a document.

## Safety notice

Always use the current product label and current official SDS for the exact product and revision supplied. Safety documentation supports professional handling and does not replace site-specific risk assessment, applicable law, approved operating procedures, PPE requirements, or professional judgement. Never mix chemical products unless the current official documentation explicitly permits it.
