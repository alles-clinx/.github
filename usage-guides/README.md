# Product Usage Guides

Public Alle's ClinX usage-guide library for professional and institutional product use.

This directory is intended to contain **36 product Usage Guide PDFs**, one for each current document variant in the published product-documentation set.

Use the current product label and controlled technical documents where a site-specific instruction differs. Product safety information belongs in the corresponding SDS.
