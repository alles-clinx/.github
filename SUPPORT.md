## GitHub issues

Public GitHub issues should be limited to matters such as:

- broken or incorrect repository links;
- document-index errors;
- metadata inconsistencies;
- typographical errors in public repository material;
- reproducible issues affecting public code or machine-readable data.

Do not post confidential commercial information, personal data, credentials, customer information or safety-critical chemical questions in a public issue.
