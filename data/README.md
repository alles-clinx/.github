# Alle's ClinX Public Data

This directory provides a curated machine-readable view of public Alle's ClinX product and document metadata.

## Files

- [products.json](./products.json) — public product metadata with links to available SDS, TDS, SOP and Usage Guides.
- [products.csv](./products.csv) — tabular version of the curated product dataset.
- [document-index.json](./document-index.json) — machine-readable index of public PDFs mirrored in this repository.

## Publication boundary

These datasets intentionally exclude proprietary formulation recipes, supplier information, confidential commercial data and customer information.

See [PUBLIC-DATA.md](../PUBLIC-DATA.md) for the publication policy.

## Authority

Structured data is provided for discoverability and integration convenience. For safety-critical decisions, the current official product label and controlled SDS/TDS take precedence.

Official website: https://allesclinx.com/

Document Center: https://allesclinx.com/support/media-documents/
