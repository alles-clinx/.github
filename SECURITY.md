# Security Policy

Alle's ClinX maintains this repository as a public technical and operational information source.

## Reporting a security issue

Please do **not** disclose security vulnerabilities through a public GitHub issue.

Send reports to **care@allesclinx.com** with the subject line **Security disclosure** and include:

- the affected Alle's ClinX service, page or repository;
- a concise description of the issue;
- reproducible steps where appropriate;
- potential impact;
- supporting screenshots or logs that do not contain unnecessary personal data.

We will acknowledge legitimate reports and route them for review.

## Scope

Security reports may include vulnerabilities affecting Alle's ClinX public digital services, repositories, published code, exposed credentials, access-control issues or unintended disclosure of non-public information.

## Out of scope

This repository is not a channel for:

- product-use or chemical-mixing questions;
- medical advice or exposure management;
- procurement disputes;
- requests for confidential formulations or supplier information;
- social-engineering attempts;
- destructive testing, denial-of-service activity or privacy-invasive testing.

For product or documentation support, see [SUPPORT.md](./SUPPORT.md).

## Chemical safety

For chemical handling, compatibility, PPE, storage or exposure information, use the current product label and official SDS/TDS. Never rely on a GitHub issue as a substitute for safety documentation or an institution's approved procedure.
